Training loss this week

Federated pretraining, in the open.

A single company training a frontier model uses thousands of A100s in a datacenter. Most people don't have that hardware. But millions of people have gaming PCs with RTX cards sitting idle. CrowdGPT pools that compute, and the model that gets trained belongs to everyone who helped build it.

01

Local training, local data.

Your GPU trains on a 1MB data chunk fetched from HuggingFace. The weight delta is the only thing that leaves your machine. Nothing else.

02

A real architecture.

500M-parameter dense transformer with grouped-query attention, SwiGLU, and RoPE. Same building blocks as Llama and Mistral, just scaled to run on consumer hardware.

03

Auditable end to end.

The client is a single Python file. No binaries, no telemetry. Read it, fork it, run your own coordinator. The model weights are downloadable.

A note on trust

Every submitted delta is validated server-side before it touches the global weights. Malformed, oversized, or statistically suspicious updates are rejected automatically, and repeat offenders lose write access. The server never executes anything a client sends; it only ever reads numbers. This makes the global server/coordinator immune to any breaking attacks.
