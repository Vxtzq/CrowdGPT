A new paradigm for training AI.

A single company training a frontier model uses thousands of A100s in a datacenter. Most people don't have that hardware. But millions of people have gaming PCs with RTX cards sitting idle. CrowdGPT uses that compute, and the model that gets trained belongs to everyone who helped build it.

Privacy first.

Your GPU trains on 10MB data chunks streamed from the public CrowdGPT dataset on HuggingFace; a dataset anyone can inspect or contribute to. No personal files, browser history, or local data are ever accessed or transmitted.

More ecological.

Trains on consumer GPUs that are already powered on. CrowdGPT requires no new datacenters, no additional hardware manufacturing, which is a huge tradeoff of traditional AI.

Transparent.

The client is a single, human-readable Python file that anyone can audit and modify. Model weights are downloadable, 100% free and open on HuggingFace.

A note on trust

The client is a single open-source Python file which is human-readable. It downloads public training data online, trains locally and uploads only the model update. It cannot access your files or compromise your machine.

The server is protected too. Every update is validated for size, NaN values and norm bounds before it is cross-validated by peers, and repeat offenders are banned from the project.

Read the source before you run it.

Install the client

Install everything with one command. Even if you don't have python/git installed.

App requirements
  • ~6 GB of free disk space. PyTorch alone is around 2.5 GB.
  • A discrete GPU is strongly recommended. NVIDIA (CUDA), AMD (ROCm / DirectML), Apple Silicon (MPS) and Intel Arc (XPU) are all supported.
  • A stable internet connection for streaming model weights and dataset chunks.
  • CPU-only mode works, but is extremely slow.

The installer handles everything else: GPU detection, the correct PyTorch wheel, Python and Git if missing, and an isolated virtual environment.

One-line install Recommended

Copy this into your terminal. It downloads the installer, auto-detects your hardware, and starts the client.

How the installer works

  1. Detect hardware. Installs the right dependencies for your Graphics Card.
  2. Install dependencies. Python and Git are installed if missing, then PyTorch from the correct index and the project's requirements; everything is inside an isolated virtual environment so nothing touches your system Python.
  3. Launch. Downloads the model weights from HuggingFace, streams a dataset chunk, and starts training. You can stop at any time.

About - How it works

How CrowdGPT coordinates thousands of independent GPUs to train a single, cohesive language model without insane infrastructure.

1. Task Assignment

When a device connects, the server assigns it a specific data shard (a 10MB chunk of tokenized text from the public CrowdGPT dataset) and the current global model weights. The client downloads the weights from HuggingFace and streams the data chunk locally via HTTP Range requests. The dataset is fully open and anyone can contribute to it.

2. Local Training

The app performs AI training on the local device. It calculates the path (the "delta") between the base model and the newly trained model. Nothing is ever accessed on your computer.

3. Secure Submission

The app then compresses the update, and sends it back to server for validation:

✓Checks for NaN or Inf values in the delta.
✓Verifies the delta size matches the model architecture exactly.
✓Ensures the delta norm is within statistically acceptable bounds to prevent poisoning.

4. Aggregation

Valid updates are averaged and applied to the global AI model periodically. Model weights are automatically pushed to HuggingFace for public auditing and usage/testing.

What the numbers mean

  • Global Step: total aggregated optimizer updates applied to the model, across all contributors.
  • Tokens Processed: cumulative tokens trained on by every GPU in the swarm.
  • Active Clients: GPUs that have pinged the coordinator in the last 10 minutes.
  • Model Loss: cross-entropy loss of the most recently aggregated update.

Stats refresh automatically every 15 seconds from the HuggingFace CDN. The global model weights are pushed to HuggingFace every 10 hours after aggregated updates complete.

Is my data safe when I run the client?
Yes. The client streams 10MB chunks from the public CrowdGPT dataset on HuggingFace, a dataset anyone can inspect or contribute to. Your personal files, browser history and any other local data are never accessed or transmitted. Only the mathematical weight delta leaves your machine.
How much disk space do I need?
Around 4 GB free. The model weights take about 1.3 GB in bf16, each dataset chunk is only 10 MB and streamed on demand, and local checkpoints for delta computation add about 1.3 GB. The client auto-cleans old checkpoints, so disk usage stays stable over time.
Does it work on AMD or Apple Silicon?
Yes. NVIDIA GPUs via CUDA are recommended for best performance. AMD GPUs are supported through ROCm on Linux (the installer picks the right ROCm wheel automatically), and on Windows AMD users can either use DirectML or run the Linux installer inside WSL2. Apple Silicon M1, M2 and M3 Macs work via the MPS backend, which is bundled with the standard macOS PyTorch wheel. CPU-only mode is supported but very slow.
Do I need to install Python or Git first?
No. The installer detects whether Python and Git are present and installs them automatically if they are missing (using your system package manager on Linux, Homebrew or the official installer on macOS, and winget or the official installers on Windows). Everything is installed into an isolated virtual environment so it doesn't affect the rest of your system.
Why did I used to get the CPU build of PyTorch?
The default PyPI wheel for torch is CPU-only on every platform. The previous install instructions used pip install -r requirements.txt, which pulled that CPU wheel even on machines with NVIDIA or AMD GPUs. The new installer explicitly picks the correct index URL (cu124, cu118, rocm6.1, xpu, or cpu) based on your detected hardware, so this can't happen anymore.
Can I run this on a CPU?
Technically yes, and the installer has a CPU fallback, but it will be extremely slow. The client is optimized for CUDA-enabled NVIDIA GPUs. If no GPU is detected it will fall back to CPU, but contributing meaningful compute will take significantly longer.
How are malicious updates prevented?
The coordinator enforces strict validation. Every submitted delta is checked for NaN/Inf values, exact size matching and norm bounds. Updates that deviate too far from expected statistical distributions are rejected, and repeat offenders are temporarily banned by subnet.
