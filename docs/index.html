home / protocol

The Federated Protocol

How independent GPUs train one model without centralizing data.

1. Task assignment

The coordinator assigns a data shard (a 10MB chunk of tokenized text from the public CrowdGPT dataset) and the current global weights. The client downloads weights and streams the chunk via HTTP Range requests.

2. Local training

The client runs forward and backward passes on its GPU and computes the delta between starting and trained weights. No raw data leaves the machine.

3. Secure submission

Only the compressed weight delta is uploaded. The coordinator validates it:

✓No NaN or Inf values.
✓Size matches the architecture exactly.
✓Norm within statistical bounds to prevent poisoning.

4. Aggregation

Valid deltas are averaged and applied with a decoupled learning rate and weight decay. Updated weights are pushed to HuggingFace for public audit and as a bootstrap for new clients.

Is my data safe?
Yes. The client streams 10MB chunks from the public dataset and uploads only the weight delta. Personal files and history are never touched.
How much disk space?
About 4 GB. Weights ~1.3 GB (bf16), chunks 10 MB streamed, checkpoints ~1.3 GB with auto-cleanup.
AMD or Apple Silicon?
Yes. CUDA is recommended; ROCm (Linux) and MPS (M1/M2/M3) are supported. CPU is slow.
How are malicious updates stopped?
Every delta is checked for NaN/Inf, size and norm bounds. Outliers are rejected and repeat offenders banned by subnet.
