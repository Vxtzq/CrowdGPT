A note on trust

The client is one open-source Python file. It reads public data and sends weight updates. Nothing else.

  • Fully auditable, no binaries, no telemetry
  • Only weight deltas leave your machine
  • It cannot access your files or compromise your PC
  • The server validates every update and bans bad actors

Federated pretraining, in the open.

Frontier labs train on thousands of datacenter GPUs. Millions of people have idle gaming GPUs. CrowdGPT pools them, and the model belongs to everyone who helped build it.

01

Local training, public data.

Train on 10MB chunks streamed from the public CrowdGPT dataset on HuggingFace. Anyone can inspect or contribute to it. Only the weight delta is uploaded.

02

A real architecture.

1B-parameter dense transformer with grouped-query attention, SwiGLU and RoPE. The same building blocks as Llama and Mistral, scaled to consumer hardware.

03

Auditable end to end.

One Python file. Read it, fork it, run your own coordinator. Weights are downloadable.

Install the client

One Python script, minimal dependencies, up and running in a minute.

Before you start
  • GPU: NVIDIA (CUDA), AMD (ROCm) or Apple Silicon (MPS)
  • Disk: about 4 GB free
  • RAM: under 4 GB in use
  • CPU-only runs but is very slow

Clone, install, run. The client detects your GPU and tunes settings automatically.

The Federated Protocol

How independent GPUs train one model without centralizing data.

1. Task assignment

The coordinator assigns a data shard (a 10MB chunk of tokenized text from the public CrowdGPT dataset) and the current global weights. The client downloads weights and streams the chunk via HTTP Range requests.

2. Local training

The client runs forward and backward passes on its GPU and computes the delta between starting and trained weights. No raw data leaves the machine.

3. Secure submission

Only the compressed weight delta is uploaded. The coordinator validates it:

✓No NaN or Inf values.
✓Size matches the architecture exactly.
✓Norm within statistical bounds to prevent poisoning.

4. Aggregation

Valid deltas are averaged and applied with a decoupled learning rate and weight decay. Updated weights are pushed to HuggingFace for public audit and as a bootstrap for new clients.

Is my data safe?
Yes. The client streams 10MB chunks from the public dataset and uploads only the weight delta. Personal files and history are never touched.
How much disk space?
About 4 GB. Weights ~1.3 GB (bf16), chunks 10 MB streamed, checkpoints ~1.3 GB with auto-cleanup.
AMD or Apple Silicon?
Yes. CUDA is recommended; ROCm (Linux) and MPS (M1/M2/M3) are supported. CPU is slow.
How are malicious updates stopped?
Every delta is checked for NaN/Inf, size and norm bounds. Outliers are rejected and repeat offenders banned by subnet.
